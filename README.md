# 🩺 Doctor Appointment App

A modern and responsive doctor appointment web application built with Vue.js.

## 🚀 Live Demo

[View Live Demo](https://doctor-appointment-app-tau-two.vercel.app/)

## ✨ Features

* Browse available doctors
* View doctor information
* Book doctor appointments
* Browse different doctor categories
* Interactive and user-friendly interface
* Responsive design for desktop, tablet, and mobile devices

## 🛠️ Technologies

* Vue.js 3
* JavaScript
* HTML5
* CSS3
* Vite

## 📱 Responsive Design

The application is fully responsive and designed to provide a smooth user experience across different screen sizes.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/MahmoudElkhawas/Doctor-Appointment-App.git
```

Navigate to the project directory:

```bash
cd Doctor-Appointment-App
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

## 🌐 Deployment

The application is deployed using Vercel.
